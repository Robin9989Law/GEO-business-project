# 05 实施控制 · 证据到条款映射

阅读日：2026-08-16。论文 37（全文）+ 博客 20（全文）+ 标准 6（另表）。  
去重只写 `研究/业务流程文献/_work/05实施控制_dedup.csv`。数字与四选一仍只认 `流程/03 测量`。

合同锚点：`sop_stage` 只读；诊断 `intervention_class=无`；冲刺一轮一类证据且只动 `treat_need_ids`；`holdout_need_ids` 禁止改页；完成日+等待后再复测；**冲刺最终 `verdict_4` 只在本步复测后写**；诊断/续约四选一抄 03。

## 1. 产品线拆分

| 产品线 | 05 只许做 | 证据 | 写成条款 | 禁止 |
|---|---|---|---|---|
| 诊断 | 监测、问题日志、变更（若有）只停、不改页/不发文 | P18 控制=对照计划收集证据；S01 变更是对**已批基线**的动作；诊断无基线干预通道 | `sop_stage=诊断` → 干预轮次卡整卡「不适用」；周报任务不得含一类证据 | 把监测波动写成「已优化」 |
| 冲刺 | 一类证据 + 完成日 + 等待 + 复测 | P36 实施前评估影响；P34 未授权不得实施；B10/B11 holdout 不得吃到赢家处理 | 一轮只勾一个 `intervention_class`；`need_id`∈`treat_need_ids` | 同时改 FAQ+列表+视频还当一轮 |
| 续约 | 滚动监测，不新开处理组、不新开因果 | P37 长窗要独立实验/holdout，不是把旧冲刺重说一遍；P35 上线后对照易被后续变更污染 | 续约禁止新开 `treat`；`verdict_4` 只许「滚动异常 / 不能下结论」 | 用结项或续约周报重开 L1 |

## 2. 干预准入

| 证据 | 发现 | 条款 | 不要抄 |
|---|---|---|---|
| S01 APM；B07 | 变更控制=捕获、评估、批准/驳回/延期**已批基线**的请求 | 冲刺改页必须先有干预轮次卡+变更单；诊断无此通道 | 把「变更管理」组织转型课当成可以改监测组 |
| P36 Change Canvas；B02 | 未评估成本/进度/范围/风险就答应=基线被静默破坏；CPI=0.70 的考题根因是未评估 | 评估未完成不得开工；评估须写清是否触及 `holdout_need_ids`（必须否） | 把 PMI 考题 1.43×EAC 写成报价系数 |
| P34 形式化 ICC | 否决不可逆；未授权不能进入 Assigned/Released | 驳回的一类证据不得在监测组或处理组「先做了再说」 | NuSMV 工具名 |
| P16 守门 | 有效治理主要是**压住未评估变更的发生**，不是把已发生变更解释小 | 准入看「有没有违规启动」，不看事后叙事 | 40.5%→4.9% 写入合同 |
| P25 SCR | 口头/聊天同意不是变更完成 | 完成以台账字段为准 | 敏捷口头站会代替台账 |
| B06 Pressbooks | 先评估三重约束与储备，再送 CCB；变更日志与问题日志并列 | 问题（issue）升格为改基线必须转变更单 | 任何问题都当一类证据 |

**条款（干预准入）**：仅当 `sop_stage=冲刺` 且轮次卡已勾唯一 `intervention_class`、`need_id`⊆`treat_need_ids`、监测组改页=否、变更单已批，才允许动处理组资产。

## 3. 完成日

| 证据 | 发现 | 条款 |
|---|---|---|
| S03 EVMS 变更程序；B01/B04 | 批准的变更必须写入绩效测量基线；完成要可审计 | 实际完成日写入 `intervention_ledger.csv`，缺完成日不得进入等待/复测 |
| P11 RealCONs；P01 ES | 进度报告与 EV 必须同源；用时间单位跟踪「做到哪一天」 | 完成日是资产落地日，不是「开始改的那天」 |
| B02 | 未入账的工作会让 EV=70% 而 AC=100% | 未写完成日视为未完成，周报不得勾一类证据已完成 |

**条款（完成日）**：复测时钟从**实际完成日**起算，不从计划日或立项日起算。

## 4. 等待期

| 证据 | 发现 | 条款 | 不要抄 |
|---|---|---|---|
| P37 产业工作坊 | 短窗无法直接量长窗；幅度会变（例：7%→2.5%）；**没有替代做对的长窗实验** | 完成日后必须经过合同等待天数，才允许 `retest` | 把「符号很少反转」写成可以当天复测 |
| B10 Drip | 程序级 holdout 建议 6–12 个月才看累积差；单测点估计相加会高估 15–30% | 等待期内不得把单测或周报噪声写成最终四选一 | 6–12 个月直接写进所有冲刺（等待天数以 04/章程为准） |
| P13 / P31 switchback | 时间切换有携带效应，间隔不足则估计差 | 等待=让携带/索引/收录效应过去，不是「再跑一天 API」 | 把论文最优切窗当成等待天数公式 |
| P02 拥堵 | 系统未回到稳态时，对照与处理互相干扰 | 等待期内监测组与处理组都按冻结计划采集，不得加新干预 | 排队模型参数 |
| S04 / B20 | 协议完成后有披露/观察时序，不得立刻宣称终点 | 类比：完成≠可下结论 | 临床试验洗脱天数 |

**条款（等待期）**：`等待天数` 未满，禁止写最终 `verdict_4`，禁止勾确认性 L1。

## 5. 监测组未改

| 证据 | 发现 | 条款 |
|---|---|---|
| B11 Airship | holdout 用户级排除；**禁止再进入其他 A/B 或序列对照组**，否则重叠污染 | `holdout_need_ids` 本轮零改页、零发文、零「顺便优化」 |
| B09 / B12 / B13 / B16 | 长期 holdout ≠ 单次实验的 control；holdout 在整个程序期内不吃赢家处理 | 监测组不是「这一周的对照组」，是章程锁定的未处理 need |
| B10 | holdout 与单测 control 常被混用；混用会把程序效果说成单测之和 | 周报不得把监测组当成反事实市场 |
| P24 / P26 / P07 / P15 | 反馈环、训练环、网络干扰会让对照不再是对照 | 监测组页面或问法被改 → 本轮复测只许「不能下结论」 |
| P35 | 上线后其他变更会同时污染处理与对照 | 复测必须同一 `{freeze_id}`；改问法=新冻结，重打基线 |
| B14 / B15 | holdout 用来量增量，点估计测量不够 | 监测组出数走 03 手册，不在 05 另造指标 |

**条款（监测组未改）**：G5 必检监测组未改页。改了则 `coverage_ok`/`measure_isolated` 失败，不得 L1。

## 6. 复测准入与最终四选一

| 证据 | 发现 | 条款 |
|---|---|---|
| P37 | 短窗代理不能替代长窗实验；决策应对齐长窗目标 | **冲刺最终 `verdict_4` 只从本步 `retest` 产生**；诊断/续约仍锁 03 |
| P35 | 事后可用暂停处理或保留 holdout；合成对照有偏、易被并发变更打坏 | 默认复测=同一冻结下的处理 vs 监测，不是合成对照 |
| P32 | 实验前数据可降方差，但不创造对照 | 不得用基线趋势外推代替复测 |
| P20 / P02 | 干扰存在时 SUTVA 不成立 | 确认性 L1 仍须 `causal_claim=did_isolated` 且 DiD CI 不含 0、簇数≥2、覆盖齐全（03 规则） |
| B03 / P01 | 挣值对照的是基线，不是「两组 CI 错开」 | 禁止把监测组与处理组的 CI 错开说成效果 |
| 模板_周报 | 诊断四选一=03；冲刺四选一=本步复测 | 周报口径不得宽于 08 `comms_bound` |

**条款（复测准入）**：同时满足：完成日已写、等待已满、监测组未改、`{freeze_id}` 未变、覆盖 P0 齐全。否则 `verdict_4=不能下结论`。

**条款（最终四选一）**：冲刺 06 验收只抄 05 复测后的 `verdict_4`。任何人不得用 03 基线四选一、周中快照或厂商看板替换。

## 9. 三条最强条款（建议锁进 05 / G5）

1. **监测组未改**：`holdout_need_ids` 本轮不得改页、发文或叠做其他实验；一经污染，本轮只许「不能下结论」。（B11、B10、P24、P35）
2. **冲刺最终 `verdict_4` 只从本步复测产生**：完成日已写且等待期满之前，禁止把短窗、单测 CI 错开或基线四选一升级为最终口径。（P37、P13、周报模板）
3. **干预准入 + 一类证据**：仅冲刺、仅一类、仅 `treat_need_ids`；未评估影响或变更被驳回不得实施；诊断整卡「无」。（P36、P34、S01、干预轮次卡）
