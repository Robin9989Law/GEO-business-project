# 研究审计整改（2026-08-16）

对照「约 3.5/5，可用于修订草案，暂不宜把同构证据单独固化为新科学门禁」。

## 已做

1. **博客名额重分类**  
   LinkedIn / Wikipedia / YouTube / Stack Exchange 以及与本站标准同一 URL 的页面，一律 `counts_toward_quota=false`。  
   补入官方或研究者全文：GOV.UK discovery / live / beta、Fowler feature toggle / canary / CI、Joel Evidence-Based Scheduling / Joel Test、Atlassian change management。  
   整改后八站博客名额均 ≥20，且上述禁入主机为 0。

2. **统一 schema**  
   见 `登记schema.md`。现行机读文件是各站 `*.统一.json`，字段含 `peer_reviewed` `quality` `directness` `checksum_sha256` `review_status` `counts_toward_quota`。  
   07 论文已从 PDF 补齐校验和。04/05/08 缺登记原件的，已从全文目录回填。

3. **第二库与引文**  
   Crossref 作为独立学术索引（2023-08 至 2026-08 期刊论文计数）；每站 **1–3** 个 DOI 走 Semantic Scholar 的被引/参考文献计数。结果：`第二库与引文追踪.json`。  
   Crossref 数字是宽检索命中量，不能当召回率。这补上「只有 OpenAlex」的缺口，但仍是检索校验，不是独立复筛。

4. **直接性标签**  
   论文默认 `同构迁移`（本领域几乎无 GEO 交付 RCT）；标准 `规范性`；厂商博客 `商业经验`。  
   硬门禁只允许：核心合同或正式标准 + 至少两项中高独立证据。见 `硬门禁资格表.csv`。  
   **未达标、不得写成定额的：** 施工/COCOMO/故事点数字、holdout 6–12 月、Green Book 上浮、厂商百分比。`wait_days` 只作记录字段，不锁行业天数。

5. **关键十篇复读**  
   `关键十篇锚点.md`。低质量论文不进该表，只留背景。

6. **口径**  
   全局表改为统一登记导出。综述数字改为「名额内论文 / 名额内博客 / 标准」。08 精读 31/32 以登记 31 篇为准。
