# 08 沟通 · 证据到条款映射

阅读日：2026-08-16。只映射能锁 G7 的句子。论文 31 + 博客 20 + 标准/经典 10。厂商统计不进合同。

目标条款（`合同/核心合同.md` G7 / `案件合同卡.md` 08 栏）：

| 字段 | 锁成 |
|---|---|
| `stakeholder_decision` | 客户决策人；只收四选一 |
| `comms_cadence` | 门通过时给决策人；每周给对接；采集日给班组 |
| `comms_bound` | 不得宽于四选一 |
| 附件顺序 | App 主表 → 监测组 → API 附表 |

## 1. 干系人分析 → `stakeholder_decision` + 登记表

| P10 Yakymchuk 2025 | 按簇选沟通战术，禁止一套话术打全员 | 矩阵按角色写频率/载体/口径 |

| C01 Mitchell 1997 / C02 Mendelow | 权力×利益（+合法性）决定优先响应谁 | API 无决策合法性 |
| B01 B03 B04 | keep satisfied / manage closely / keep informed / monitor | 决策人 keep satisfied=结论包；对接 manage/inform=周报 |

## 6. 四选一话术 → `comms_bound`

| 证据 | 原句/发现 | 条款 |
|---|---|---|
| P27 | 沟通是归因源头；走过场式沟通会被当成不公 | 对外只说 03 已允许的四选一句子 |
| S07 IAP2 | 对外承诺的参与深度不得高于授权 | 诊断=告知「现在长什么样 / 不能下结论」；不得预告会涨 |
| S04 AA1000SES | 按实质性议题回应 | 实质=无品牌发现问上的 `p_mention`；咨询/报名只观察 |
| P08 | 自适应不能变成现场改口 | 08 只分配听众，不改 02 允许集 |
| 核心合同 | `causal_claim` 默认 descriptive；08「沟通不得升级」 | `comms_bound=不得宽于四选一` |

**允许对外说（抄 03，08 不发明）：** 描述基线 / 受控前后描述 / 确认性 L1 / 不能下结论——且必须落在该 `sop_stage` 允许集内。

**禁止：** 保证推荐、报名因此增长、七家平均、未冻结对比、未噪声解释涨跌、把监测组说成反事实。

## 7. App 主表 → 监测组 → API 附表

| 证据 | 原句/发现 | 条款 |
|---|---|---|
| B01 / B22 / S03 | 高管要影响摘要；技术团队要细节；指导层不收作业数据 | 决策包=App 主表（用户所见）+ 四选一 |
| P22 / P25 | 技术管道与业务结论之间必须有桥梁；EIR/传感器不是决策包 | API 只能当附表，证明采集痕迹 |
| P23 / P33 | 富媒介/正式包给决策；瘦媒介给状态同步 | API 波动属瘦媒介噪声，不进决策人包 |
| P04 / P28 | 全员透明仍要权限；PMO 统一口径 | 内部负责人可看全套；决策人默认不看附表 |
| 核心合同 / 03 手册 | 数字与四选一只认测量手册 | 主表口径=用户所见 App；监测组分列；API 不得平均进主列 |

**附件顺序（锁死）：**

1. **App 主表**（处理组/监测组分列，`p_mention`，`verdict_4`）  
2. **监测组**（对照，非反事实）  
3. **API 附表**（可选；仅内部或应要求；标明「非用户所见」）

## 8. 决策人不得以 API 为主表

| 证据 | 原句/发现 | 条款 |
|---|---|---|
| P21 四分 + B01 | 高权低利/决策人 keep satisfied：少细节 | API 明细=过量细节 |
| P22 | 高 salience 角色看的是业务结论，不是管道 | 决策人收四选一，不收 API |
| P25 / P16 | 信息需求先于数据源；自动化不得改主结论 | 主表定义权在 03 冻结，不在 API |
| P23 媒介 | 错误信道会把噪声当成信号 | 把 API 日波动发给决策人=程序错误 |
| S03 / B17 / B22 | 指导层/高管会禁止任务清单与原始日志 | API 视同原始日志 |
| G7 原文 | 「决策人不以 API 为主表」 | 本案硬规则，文献只提供同构理由 |

**写入案件合同卡：** 「决策人不以 API 为主表 = 是」。若客户坚持 API 主表 → 停在 G7，不开采。
