# 10 项目文件规则

本案库路径：`流程/10 项目文件/案件/{本案}/`。通用模板在本目录 `模板/`，开单复制，不改原件。

## 1. 原始资料

- Agent 引导人做的每一份材料、数据，必须进 `原始/{阶段}/`，并在 `原始/登记.csv` 留一行。  
- 人可以先丢 `agent_pm/cases/{本案}/inbox/`；Agent 在 `apply` 时转入原始库。  
- 原始只追加，不删、不改内容。同名不同校验和则另存一档。  
- 客户原话即使含禁售句也要原样保存，放入 `原始/{阶段}/隔离/`，标记 `quarantine`。  
- `流程/03 测量/` 下的冷问、截图、台账：**登记指针，不复制**。金标准仍只认测量目录。

## 2. 正式文件配置管理与版本

- 正式件 = 过了当前门、可被后一站引用的文件。  
- 配置源是 `正式/清单.csv`：`doc_id`、版本 `rev`、校验和、门、阶段、现行/历史。  
- 发布只许追加 `正式/版本/vNNN/`，再刷新 `正式/现行/`。禁止直接改现行充新版。  
- 要改现行：`checkout` 上锁 → 改副本 → `checkin` 出下一 `rev`。别人锁着时不得发布。  
- 禁售扫描**只拦正式发布**。隔离区的原话不得 `promote`。  
- 诊断单的正式件不得出现干预 / 一类证据 / 确认性 L1 作为交付。

## 3. 成员中转、版本与交互

- 互传不走私人聊天当唯一副本。一律 `中转/收件/` → 接收人 `待取/` → 确认后 `已取/`。  
- `中转/往来.csv` 追加 drop / pick / ack。`中转/看板.md` 是实时交互面：每次开口先读。  
- G8 要求 `close_board_empty=是`：待取已 pick/ack，看板无未取件。  
- 接收人必须是该条的 `receiver`。取错人拒绝。  
- 中转件也做校验和；正式改版仍走第 2 节，中转不是正式发布。  
- 成员只用角色代号（操作员 / 评分 / 编排 / 负责人），不把真名写进模板原件。

## 4. 权威

测量数字与四选一仍只认 `流程/03 测量`。本库管「文件在哪、哪一版现行、谁传给谁」，不放宽口径。
