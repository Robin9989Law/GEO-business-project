# 10 项目文件规则

本案库路径：`流程/10 项目文件/案件/{本案}/`。通用模板在本目录 `模板/`，开单复制，不改原件。

## 1. 原始资料

- Agent 引导人做的每一份材料、数据，必须进 `原始/{阶段}/`，并在 `原始/登记.csv` 留一行。  
- 人可以先丢 `agent_pm/cases/{本案}/inbox/`；Agent 在 `apply` 时转入原始库。  
- 原始只追加，不删、不改内容。同名不同校验和则另存一档。  
- 客户原话即使含禁售句也要原样保存，放入 `原始/{阶段}/隔离/`，标记 `quarantine`。  
- `流程/03 测量/` 下的冷问、截图、台账：**登记指针，不复制**。金标准仍只认测量目录。

## 2. 正式文件配置管理与版本

- 正式件 = 过了当前门、可被后一站引用的文件。  
- 配置源是 `正式/清单.csv`：`doc_id`、版本 `rev`、校验和、门、阶段、现行/历史。  
- 发布只许追加 `正式/版本/vNNN/`，再刷新 `正式/现行/`。禁止直接改现行充新版。  
- 要改现行：`checkout` 上锁 → 改副本 → `checkin` 出下一 `rev`。别人锁着时不得发布。  
- 禁售扫描**只拦正式发布**。隔离区的原话不得 `promote`。  
- 诊断单的正式件不得出现干预 / 一类证据 / 确认性 L1 作为交付。

## 3. 成员中转、版本与交互

- 互传不走私人聊天当唯一副本。一律 `中转/收件/` → 接收人 `待取/` → 确认后 `已取/`。  
- `中转/往来.csv` 追加 drop / pick / ack。`中转/看板.md` 是实时交互面：每次开口先读。  
- G8 要求 `close_board_empty=是`：待取已 pick/ack，看板无未取件。  
- G8 要求 `close_manifest_ok=是`：`正式/清单.csv` 不得为空；须有 01_商机卡 / 02_章程 / 07_预算 / 08_沟通矩阵 / 04_进度 / 05_周报 / 06_验收单；每条现行件的门须已 APPROVE；`正式/现行/` 不得有未登记文件；`正式/版本/` 归档哈希仍匹配。  
- G8 批准前必须已有 `out/09_结项报告.md` `out/09_经验教训.md` `out/09_资产移交.md`；批准后才升正式版。  
- `close_archive_ok=是` 不是「无签出锁」：须 `deposits.csv` 有本案 `project_anon`、移交件在、脱敏扫描通过；冲刺还须 `plays.csv` 一行。
- 接收人必须是该条的 `receiver`。取错人拒绝。  
- 中转件也做校验和；正式改版仍走第 2 节，中转不是正式发布。  
- 成员只用角色代号（操作员 / 评分 / 编排 / 负责人），不把真名写进模板原件。

## 4. 写入保护（现在就要，不建库）

文件系统仍是唯一事实源。不引入 SQLite / 独立数据库。登记 CSV 必须：

- 先写临时文件再 `replace`，禁止直接截断目标文件。  
- 同一案件的原始入库、正式发布、中转、看板共用 `.write.lock`。  
- `登记.csv` 的 `raw_id`、`清单.csv` 的 `doc_id+rev`、`锁.csv` 的 `doc_id`、`成员登记.csv` 的 `member_id` 不得重复。  
- `看板.md` 与 `board.json` 成对替换；机器以 `board.json` 为准，人看 `看板.md`。  

核对（只在内存重建索引，不落库）：

```text
python3 agent_pm/run.py check-vault 本案
python3 agent_pm/run.py check-vault ALL
```

以后若活跃案件 >30、任一登记 CSV >5MB、或同一案件真实并发写入成为常态，再在 `流程/10 项目文件/索引/catalog.sqlite3` 建可重建元数据索引。在此之前不建库。

## 5. 权威

测量数字与四选一仍只认 `流程/03 测量`。本库管「文件在哪、哪一版现行、谁传给谁」，不放宽口径。
