# 10 项目文件

全程文件工作区。Agent 驱动，人交件和取件。不是 09 之后的第十步。

三件事：

1. **原始资料**：Agent 带人做出来的材料、数据，原样进本案 `原始/`。  
2. **正式文件配置与版本**：过门后的正式件进 `正式/`，现行一份、历史按版本留，禁止原地覆盖。  
3. **成员中转**：互传走 `中转/`，看板显示谁给谁留了什么；取走、确认都留痕。

| 文件 | 用途 |
|---|---|
| [AGENT.md](AGENT.md) | 本步怎么带人 |
| [规则.md](规则.md) | 什么进哪、怎么升版、测量只登记指针 |
| [模板/入库单.md](模板/入库单.md) | 原始入库说明 |
| [模板/正式发布单.md](模板/正式发布单.md) | 升正式版时对照 |
| [模板/中转单.md](模板/中转单.md) | 成员互传说明 |
| [模板/清单.csv](模板/清单.csv) | 正式配置管理表头 |
| [模板/原始登记.csv](模板/原始登记.csv) | 原始登记表头 |
| [模板/往来.csv](模板/往来.csv) | 中转往来表头 |
| [模板/成员登记.csv](模板/成员登记.csv) | 成员代号 |
| [模板/看板.md](模板/看板.md) | 看板空页 |
| `案件/` | 开单实例，不是模板 |

开单：`python3 agent_pm/run.py init 本案` 会在 `案件/{本案}/` 建好三区。  
核对登记与文件夹是否一致（内存重建，不建库）：`python3 agent_pm/run.py check-vault 本案`。
