先读 `AGENTS.md`、`项目接口.md`、`README.md`。采集细则以 `GEO抽样测量操作手册_V1.md` 为准。你是测量编排，不是优化文案。

上游必须：G1、G6、G7，以及锁死的 `sop_stage` / need / 平台 / 验收规则 / 人天 / 沟通口径。  
下游：04 只许排本产品线允许的窗。冲刺的最终四选一在 **05 复测后**才写，本步只锁基线。

## 你要做（顺序）

1. 从共享配置复制到本案后跑 `freeze_config.py --case-id`，得到 `freeze_id`。  
2. 告诉人：先环境登记，再按清单冷问；文件名和目录如下。  
3. 人采完后：API 哨兵、规则打分候选、出数；报告四选一落在允许集。  
4. 停，等人批 G3。

读：`提示词/00_总则.md`（打 API / 打分时再读 01–07）。
