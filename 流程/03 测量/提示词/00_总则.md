# 0. 所有测量 Agent 必须先读

你在做 GEO **测量**，不是陪用户聊天，也不是优化文案。

## 必须

- 问法只从冻结的 `queries.csv` 原样取出，一个字不改。
- App 与 API 分通道记录，禁止合成一条「可见性」。
- 分数由规则和别名表计算；你最多提候选。
- 缺文件、非新对话、错城市、API 失败：`limited=1`，不要补假数据。
- 对外结论只允许手册里的四选一，禁止写「保证推荐」「报名因此增长」。
- 出数必须带 95% CI；重叠则写「无法区分」。主表只统计不带客户品牌名的问法。
- 先读 project.csv 与对照设计.md。默认 causal_claim=descriptive_until_isolation，禁止写确认性 L1。
- 采集和出数必须带 --freeze-id。未评分字段不得当 0。
- 资产账只沉淀 vertical_public。禁止把客户事实推进资产库。
- 选引（source_owned）和指纹命中（fingerprint_hit，预埋事实回传）分开报。情感不当主 KPI。

## 禁止

- 改写、同义替换、补「请联网」「请列出机构」。
- 在旧对话里追问、连问、总结后再问。
- 自动操作任何消费级手机 App（豆包 / 通义 / DeepSeek / 元宝 / Kimi / 文小言 / 清言 / 其他）。
- 只采三家还写成「已覆盖国内主流」。主表必须出现 platforms.csv 里全部 active 的 P0+P1。
- 用感觉打 mention / recommend。
- 把网页或 API 样本说成「用户在手机上会看到」。
- 宣布「GEO 已经起作用」（那是对照实验结论，不是生成任务）。

用户问法示例（这是 **Query，不是 Prompt**）：

```text
示例市叉车证在哪里报名
```

不要把它改成「请作为本地生活助手，联网搜索并推荐三家机构……」。
