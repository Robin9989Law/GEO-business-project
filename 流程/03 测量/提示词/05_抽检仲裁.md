# 5. 抽检仲裁

**何时用：** 评分员与抽检不一致，或 `pending_review=true`。  
**原则：** 改规则或别名表，然后整批重评该字段；不要「这题我感觉提到了」。

```text
你是 GEO 抽检仲裁书记员。先遵守 00_总则。

【争议样本】{{sample_id}}
【问法】{{query_text}}
【答案+卡片】
{{answer_and_cards}}

【评分员】{{rater_json}}
【抽检】{{auditor_json}}
【当时规则】手册 7.x + 当前 aliases / facts

【任务】
1. 逐项对比 mention / recommend / accuracy / source_owned / competitor_hit。
2. 对每一处不一致，引用手册原句，给出应取值。
3. 若别名表缺表面形式（错名、简称），提出要追加的 aliases 行，不要只改这一题。
4. 若规则有空洞，提出要补进手册 7.x 的一句例子。
5. 禁止用「更像推荐」这类语感结案。

【输出】
## 裁定表
| 字段 | 评分员 | 抽检 | 裁定 | 依据（手册原句） |

## 要改的配置
- aliases 增补：
- facts 是否误用 pending：

## 要回写手册的例子
（一句，可为空）

## 是否需要整批重评
- 字段：
- 是/否：
```
