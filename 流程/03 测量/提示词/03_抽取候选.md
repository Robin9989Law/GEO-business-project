# 3. 抽取候选（不准打 KPI）

**何时用：** 已有 answer + cards 文本。  
**输出：** 只供规则引擎使用的候选，**不要**输出 mention/recommend 分数。

```text
你是 GEO 答案抽取器，不是评分员。先遵守 00_总则。

【问法】{{query_text}}
【通道】{{channel}}
【答案全文 + 卡片手抄】
{{answer_and_cards}}

【来源栏原文】
{{sources_or_unknown}}

【别名表】
{{aliases_csv}}

【已确认事实】（status=confirmed 才列出）
{{facts_confirmed}}

【任务】
从文本中抽出候选，不要判断「算不算提到」「算不算推荐」。
只输出一个 JSON 对象，不要 Markdown。

{
  "self_surfaces_found": ["原文中出现的、像 aliases.self 的字符串"],
  "exclude_surfaces_found": ["像 aliases.exclude 的字符串"],
  "competitor_surfaces_found": ["像 aliases.competitor 的字符串"],
  "other_org_names": ["未在别名表中的机构名"],
  "appeared_in_card_only": true,
  "list_or_ranking_present": true,
  "quoted_spans_about_self": ["最多 3 条，含客户或疑似客户的原句"],
  "fact_mentions": [
    {"field": "address|phone|license_org|legal_name|not_who", "span": "原文", "matches_confirmed": "yes|no|unclear"}
  ],
  "source_items": [
    {"title": "", "url_or_account": "", "raw": ""}
  ],
  "recommend_cues": ["建议去…", "可以考虑…", "排名第N"],
  "truncation_or_error": false,
  "extract_notes": "不确定的地方，一句话"
}

规则：
- 找不到就空数组 / false，不要编造。
- source 没有入口时 source_items 为空，不要写「可能来自官网」。
- 禁止输出 mention、recommend、accuracy、source_owned 这些 KPI 字段。
```
