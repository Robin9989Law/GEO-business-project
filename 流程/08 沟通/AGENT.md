# 08 沟通 · 节点提示词

先读 `AGENTS.md`。本步是全流程第 4 站，在测量之前锁定「谁听什么、话说到哪」。

入口：G6。唯一任务：锁决策人、节奏、`comms_bound`、`comms_api_not_primary=是`。附件顺序 App 主表→监测组→API 附表。人交干系人代号；Agent 查决策人不以 API 为主表。正式产物：沟通矩阵。G7 硬检。打回：补决策人或改口径。归宿 `原始/08/`。下一站 03。

## 你在哪

预算已批，采集还没开始。先登记干系人和对外口径，避免出数后有人把 API 当主表，或把四选一升级成效果承诺。

上游必须：G6，以及 02 的 `sop_stage` 允许集。  
下游：03 出数按本步矩阵分发；05 周报 / 纪要不得宽于本步 `comms_bound`；06 决策人只收四选一。

门：**G7**。

## 先弄清的情况

- 谁是客户决策人（只收四选一结论，不发 API 附表当主表）？  
- 谁是对接（收周报 + Issue）？谁是内部负责人（收全套）？  
- `comms_bound` 必须写明「不得宽于四选一」。  
- 诊断阶段对外只能说「现在长什么样 / 不能下结论」，不能预告「优化后会涨」。  
- 附件顺序永远：App 主表 → 监测组 → API 附表。

## 你要做

1. 告诉人：现在锁沟通；采集开始后不能再临时发明口径。  
2. 读 `干系人登记.csv` `沟通矩阵.md` `模板_会议纪要.md`。  
3. 起草本案沟通矩阵到 `out/`，写入 `stakeholder_decision` `comms_cadence` `comms_bound`。  
4. 停，等人批 G7。

## 需要人做

1. 用代号给出决策人 / 对接 / 负责人，不要把真名写进通用模板原件。  
2. 确认决策人不看 API 主表。  
3. 批准沟通矩阵。

## 材料放哪

| 材料 | 路径 |
|---|---|
| 干系人名单 | `agent_pm/cases/{本案}/inbox/08_干系人.md` |
| 本案沟通矩阵 | `agent_pm/cases/{本案}/out/08_沟通矩阵.md` |
| 过程纪要（05/06 持续写） | `agent_pm/cases/{本案}/out/08_纪要.md` |

## 然后

G7 批准 → 打开 `流程/03 测量/AGENT.md`。此后每次对外说话都先核对 `comms_bound`。
