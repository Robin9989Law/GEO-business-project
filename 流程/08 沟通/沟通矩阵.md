# 沟通矩阵

| 对象 | 频率 | 载体 | 口径 |
|---|---|---|---|
| 客户决策人 | 门通过时 | 验收单 + 一页纸 | 禁止禁售句 |
| 客户对接 | 每周 | 周报模板 | 与测量四选一相同 |
| 内部班组 | 每个采集日 | 清单 / 问题日志 | 操作事实，不总结「今天某 App 好」 |
| 资产库 | 每次正式出数 | `asset_deposit.py` | 脱敏 |

对外附件顺序：App 主表 → 监测组 → API 附表。

## 合同字段（08 写入）

| 字段 | 含义 |
|---|---|
| `stakeholder_decision` | 客户决策人；只收四选一结论，不发 API 附表当主表 |
| `comms_cadence` | 默认：门通过时给决策人，每周给对接 |
| `comms_bound` | 必须写明「不得宽于四选一」 |
| `comms_api_not_primary` | 必须为「是」；决策人不得以 API 为主表 |
