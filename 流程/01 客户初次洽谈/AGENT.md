# 01 洽谈 · 节点提示词

先读仓库根目录 `AGENTS.md`，再读本页。

## 你在哪

核心链第一步。只判断接不接、接哪条产品线。不采集、不承诺效果、不改页面。

上游：无。下游：02 把意向**收窄锁定**，不能加宽。

门：**G0**。人确认禁售并批准后才许进 02。

## 先弄清的情况

- 客户怎么描述「想被 AI 问到」？（要原话）  
- 品类口头说法、城市、内部代号（禁止在通用文件里写全称）。  
- 意向：诊断 / 冲刺 / 续约，只能一条。  
- 有没有要保证推荐、保证报名？有则停，改口到「无品牌发现问上的提及概率」，否则不立项。

## 你要做

1. 开口先说：现在在 01；先读禁售再报价；请对方把原话放到指定路径。  
2. 读 `禁售清单.md` `模板_商机卡.md` `模板_范围边界.md`。  
3. 根据人提供的材料起草商机要点（字段：`vertical` `city` `client_code` `sop_stage_intent`）。  
4. 停，等人批 G0。

## 需要人做

1. 先打开并确认已读 `流程/01 客户初次洽谈/禁售清单.md`。  
2. 给出品类、城市、代号、意向产品线。  
3. 明确：批 / 不批进入需求锁定。

## 材料放哪

| 材料 | 路径 |
|---|---|
| 客户原话 | `agent_pm/cases/{本案}/inbox/01_客户原话.md` → Agent 转入 `流程/10 项目文件/案件/{本案}/原始/01/` |
| 禁售已读 | `agent_pm/cases/{本案}/inbox/01_禁售已读.txt` → 同上原始库 |
| 你起草的商机卡 | `agent_pm/cases/{本案}/out/01_商机卡.md`（G0 后进 `流程/10 项目文件/案件/{本案}/正式/现行/`） |

## 然后

G0 批准 → 打开 `流程/02 需求文档/AGENT.md`。驳回则留在 01 改口或结束。
