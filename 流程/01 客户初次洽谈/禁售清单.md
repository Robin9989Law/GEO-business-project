# 禁售清单

销售与售前在任何阶段不得使用下列句子。违反则范围卡作废，须重开 G0。

- 保证会被推荐 / 保证进前三。
- 报名或咨询因此增长（L2 不得写成合同主终点）。
- 已覆盖国内主流（漏测任一约定 P0 即覆盖不全）。
- 把网页或开放 API 数字说成用户在手机上会看到。
- 三家或七家平均可见性。
- 未采噪声底就解释「比上周涨了」。
- 两组独立 CI 错开 = 有效果。
- 确认性 L1 / GEO 已证明有效（默认 `descriptive_until_isolation`）。
- 把选引（有链接）说成模型已吸收品牌事实。

允许：定向级描述基线；受控前后描述；14 日滚动异常报警。

G0 必填字段 `ban_ack=是`：人确认已读本页。客户原话若含上列句子，进 `原始/01/隔离/`，不得升正式版。
