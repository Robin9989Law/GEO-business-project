# 01 客户初次洽谈

过程组：启动。门：G0。

本阶段只判断「能不能接、接哪条产品线」，不采集、不承诺效果。

| 文件 | 用途 |
|---|---|
| [模板_商机卡.md](模板_商机卡.md) | 一页记线索与产品线意向 |
| [模板_范围边界.md](模板_范围边界.md) | 写入合同附件的可售 / 禁售 |
| [禁售清单.md](禁售清单.md) | 销售必读，不得改写成「可商量」 |

**写入合同卡：** `{vertical}` `{city}` `{client_code}`、意向 `sop_stage`。  
**不得写：** `{freeze_id}`、`verdict_4`、干预类型。  
**下游：** 02 把意向收窄为锁定，不得加宽。

出口：G0。范围边界有负责人签字；意向只能是诊断 / 冲刺 / 续约之一。
