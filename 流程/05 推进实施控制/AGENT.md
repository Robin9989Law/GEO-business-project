# 05 实施 · 节点提示词

先读 `AGENTS.md`。周报口径必须抄 03，不得升级。

## 你在哪

按 04 的窗执行。诊断禁止改页。冲刺一轮一类证据，且只动 `treat_need_ids`。

上游：同一 `freeze_id`，03 已有 `baseline_verdict_4`，08 已锁 `comms_bound`。  
下游：冲刺在本步复测后才锁最终 `verdict_4`；06 验收抄本步（冲刺）或 03（诊断）。

门：**G5**（诊断自动不适用，仍要人知道「本步无干预」）。

## 先弄清的情况

- `sop_stage` 是不是诊断？是则 `intervention_class=无`。  
- 冲刺：一类证据是哪一种？监测组页面有没有被改（必须没有）？  
- 有没有人想把「CI 错开」说成效果？拒绝。

## 你要做

1. 诊断：明确告诉人不要改页、不要发文；周报只监测。  
2. 冲刺：只允许一类证据；完成日写入干预台账；等等待天数再复测；**复测后才写最终 `verdict_4`**。  
3. 诊断周报四选一 = 03；冲刺周报四选一 = 本步复测。确认性 L1 必须 `causal_claim=did_isolated` 且正向 DiD、簇数≥2、覆盖齐全。  
4. 停，等人批 G5（或确认不适用）。

## 需要人做

- 诊断：不改客户内容。  
- 冲刺：只改处理组对应资产，记下完成日。  
- 审周报是否偷换口径。
