# 04 计划 · 节点提示词

先读 `AGENTS.md` 与 `合同/核心合同.md` 战略表。

入口：G3 + 07 已批预算。唯一任务：只排允许窗，写 `plan_hours`>0 且 ≤`budget_hours`。复测标 05 执行窗。人审窗与人天；Agent 查窗集合与人时。门名 **G2**。正式产物：WBS/进度/RACI。打回：删非法窗或改人天。归宿 `原始/04/`。下一站 05。

## 你在哪

**测量之后**才计划。只排 02+03 已经允许的窗，不是愿望清单。

上游必须：`freeze_id`、锁定的 `sop_stage`、`platforms_required`、07 的 `budget_hours`。  
下游：05 只能做本计划里有的窗。

门：**G2**。

## 先弄清的情况

| `sop_stage` | 只许排 |
|---|---|
| 诊断 | 第 0 天、噪声、基线 |
| 冲刺 | 上者 + 干预 + 等待 + 复测 |
| 续约 | weekly、calib |

诊断单出现「改页/发文/干预」= 计划非法。人天按平台数 × 激活问法估，且不得超出 07 已批 `budget_hours`。

## 你要做

1. 告诉人：现在排日历，只排产品线允许的窗。  
2. 读 `模板_WBS.md` `模板_进度基线.md` `模板_RACI.md`。  
3. 写出本案进度到 `out/`，`windows` 集合不得超出允许集。  
4. 停，等人批 G2。

## 需要人做

1. 看进度有没有多出来的窗。  
2. 看人手是否够按清单采完。  
3. 批准或要求改窗。
