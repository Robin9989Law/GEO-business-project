# 07 预算 · 节点提示词

先读仓库根目录 `AGENTS.md`，再读本页。本步是全流程第 3 站，不是支撑附件。

## 你在哪

需求已锁，还不能去采 App。先把人天和报价范围锁死，避免后面按冲刺的活按诊断的钱做，或把确认性 L1 卖进报价。

上游必须：G1，以及锁死的 `sop_stage` / `platforms_required` / `treat_need_ids`。  
下游：08 按本步范围登记沟通；03 按本步人天派采集；04 进度人天不得超出本步。

门：**G6**。人确认报价排除 L1、诊断不含干预行之后才许进 08。

## 先弄清的情况

| `sop_stage` | 预算只覆盖 | 禁止写进必做行 |
|---|---|---|
| 诊断 | 冻结、噪声、基线、抽检、收尾 | 一类证据、改页、干预、确认性 L1 |
| 冲刺 | 上者 + 一类证据 + 复测 | 把 L1 写成默认交付 |
| 续约 | weekly、calib、抽检 | 新开处理组、重开 L1 |

- 人天公式：激活问法数 × `platforms_required` × 本产品线允许轮次。对照 `工时标准.md`。  
- `quote_excludes_l1` 必须是「是」。  
- `budget_scope` 必须等于当前 `sop_stage` 允许集，诊断不得出现「干预 / 一类证据 / 改页」。  
- 客户成交价不要写进 `流程/07 预算和资源管理/` 原件，只写本案 `out/`。

## 你要做

1. 开口先说：现在在 07；先估人天再报价；诊断单没有改页这笔钱。  
2. 读 `工时标准.md` `预算表.csv`。  
3. 起草本案预算到 `out/07_预算.md`，写入字段 `budget_hours` `budget_scope` `quote_excludes_l1`。  
4. 停，等人批 G6。

## 需要人做

1. 给出可用人天、角色（操作员 / 评分 / 编排），不要编客户价目进模板。  
2. 确认报价书面排除确认性 L1。  
3. 批准或要求改人天。

## 材料放哪

| 材料 | 路径 |
|---|---|
| 人手与单价约束 | `agent_pm/cases/{本案}/inbox/07_人手.md` |
| 本案预算 | `agent_pm/cases/{本案}/out/07_预算.md` |
| 通用算法（只读） | `流程/07 预算和资源管理/工时标准.md` `预算表.csv` |

## 然后

G6 批准 → 打开 `流程/08 沟通/AGENT.md`。还不到 `流程/03 测量/`。
