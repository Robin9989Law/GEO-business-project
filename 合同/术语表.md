# 术语表

对外沟通优先用完整名称，避免把「L1」同时当作层级、指标和交付结论。

| 术语 | 含义 |
|---|---|
| `p_mention` | 主终点：无品牌发现问上是否被正确提及。 |
| `p_recommend` | 次要终点：是否被推荐。不等于报名或成交。 |
| App 可见性 | 用户在手机 App 冷会话中实际看到的结果。金标准。 |
| API 哨兵 | 同日校准与异常提示，不是用户所见。 |
| 监测组 | 同品类同城、本轮未优化的比较对象。不是反事实。 |
| 噪声底 | 自然波动，不是效果。 |
| 受控前后描述 | 冲刺默认结果，不是确认性因果。 |
| 确认性 L1 | 仅冲刺复测后、隔离设计已成立、DiD 不含 0、覆盖与簇数达标时才可写。 |
| `causal_claim` | 02 必须锁 `descriptive_until_isolation`。`did_isolated` 只在 05 确认性 L1 通过后写入。 |
| 项目账 | 只服务本案。 |
| 资产账 | 只沉淀可迁移结构，不进客户事实。 |
| 人时 | 工时单位。1 人时 = 1 人 × 1 小时；1 人天 = 8 人时。 |

数字与四选一只认 `流程/03 测量` 手册和出数脚本。
