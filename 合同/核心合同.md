# 核心合同（01→09 全流程唯一总线）

全流程只有这一条，顺序不得颠倒。文件夹编号是标签，行走顺序如下：

```text
01 洽谈 → 02 需求 → 07 预算 → 08 沟通 → 03 测量 → 04 计划 → 05 实施控制 → 06 交付 → 09 收尾
```

07 预算和 08 沟通在测量前锁定，不是交付后的附件。09 收尾在 G4 之后关门，G4 通过不是结案。

**单位约定**：所有 `*_hours` 字段（`budget_hours` / `plan_hours` / 任何派生 hours）统一为「人时」（person-hour）。1 人时 = 1 人 × 1 小时；1 人天 = 8 人时。出现 "人天" 一律改写或换算。`plan_hours` 与 `budget_hours` 必须同单位、可直接比较。

Agent 经 `agent_pm/run.py` 写 `state.json`。[案件合同卡.md](案件合同卡.md) 是字段说明。规格层目录见 [README.md](README.md)。后一阶段不得改已锁定字段；人 `CHANGE` 后 Agent 从锁定点重做。

**三套 `success_rule_*` 允许集**（02 写入时引擎按 `sop_stage` 对照）：

- `success_rule_diagnosis` ∈ {描述基线, 不能下结论}
- `success_rule_sprint` ∈ {受控前后描述, 确认性 L1, 不能下结论}
- `success_rule_retain` ∈ {不能下结论} （续约默认）

**`budget_scope` 与 `sop_stage` 对应集**（07 写入时引擎硬校验）：

- 诊断：`{冻结, 噪声, 基线, 抽检, 收尾}`，禁含 `干预 / 一类证据 / 改页`
- 冲刺：诊断集 ∪ `{干预, 一类证据, 复测, 等待}`
- 续约：`{weekly, calib, 监测, 收尾}`

| `sop_stage` | 07 只许报 | 03 只跑 | 04 只许排（窗） | 05 只许做（窗） | 06 只许收 | 09 只许关 |

## 3. 门（贴在全流程上）

```text
01 --G0--> 02 --G1--> 07 --G6--> 08 --G7--> 03 --G3--> 04 --G2--> 05 --G5--> 06 --G4--> 09 --G8-->
```

- G0：范围边界签字；禁售已读；若客户要保证推荐则停在 01。  
- G1：章程批准；验收标准字段齐；`sop_stage` 从意向变成锁定。  
- G6：人时按平台×问法；`quote_excludes_l1=是`；诊断 `budget_scope` 不含干预。  
- G7：干系人已登记；`comms_bound` 不得宽于四选一；决策人不以 API 为主表。  
- G3：02 的 need / 平台 / 验收已写入本案冻结且与 state 一致；采集只写 `案件/{case_id}/`。  
- G2：04 的 WBS/进度只能包含当前 `sop_stage` 允许的窗；`plan_hours`>0 且不超过 07 `budget_hours`。冲刺复测是 05 执行窗，不是 03 基线。门名只写 G2，不用 G2′。  
- G5：仅冲刺；`intervention_need_ids` ⊆ 02 处理组；完成日 + 等待；`holdout_untouched=是`。冲刺最终 `verdict_4` 只从本步复测写。  
- G4：`verdict_4` = 诊断抄 03、冲刺抄 05 复测；`freeze_match=是` 必须证明出数来自该冻结（`evidence_manifest` / `coverage.csv` / `metrics_daily.csv` 的 `project_id` `freeze_id` `config_checksum` 与本案一致，且 manifest 哈希绑住 `metrics_daily.csv`）；哈希范围必须同时包含 `metrics_daily.csv`、`coverage.csv`、`evidence_manifest.json` 与客户可见 Markdown/PDF 报告，缺一不可；`delivery_accepted=是` 才许进 09。  
- G8：资产沉淀不泄漏（`deposits.csv` 有本案 `project_anon`、结项三件已起草、无泄漏、冲刺有 `plays.csv`）；结项四选一 = 06；`close_no_reopen_l1=是`；正式清单不得为空，须含 01/02/07/08/04/05/06 预期正式件且门已批、现行无未登记文件、版本哈希仍匹配；中转清空。批准前先核 `out/09_结项报告.md` `out/09_经验教训.md` `out/09_资产移交.md`。
