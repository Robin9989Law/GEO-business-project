# 模板使用说明

全流程按 [核心合同.md](核心合同.md) 走 01→02→07→08→03→04→05→06→09。Agent 用 `agent_pm/run.py` 写 `state.json`。模板是产出图式。人只 `decide`。

## 原则

- 模板是通用空白件，不是某一客户的档案。
- 开单复制，不改原件。
- 花括号见 `项目流程SOP.md` 第 0 节。
- 客户全称、电话、地址、价格、通过率只进该单工作副本和 `流程/03 测量/配置/`（且受资产政策约束），不回写模板。

## 检查

从项目根运行：

```bash
python3 check_pm_system.py
```

失败则缺文件，或通用模板里写进了具体客户字样。实现见 `工程/check_pm_system.py`。
