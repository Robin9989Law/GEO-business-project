# GEO 项目流程 SOP（通用）

本文件是整条交付链的总控。项目人员把本文件夹交给 Agent 即开工：先读根目录 `AGENTS.md`，再读当前节点 `AGENT.md`。人只交材料和拍板。不必另做软件。`agent_pm/run.py` 可选。

测量是验收系统。本 SOP 只规定工序和门；可见性数字、L1 判定、出数口径只认 `流程/03 测量/`。  
核心链字段与战略口径以 [核心合同.md](核心合同.md) 为准。本文件在 `合同/`。运行时由 Agent 写入 `agent_pm/cases/*/state.json`，人只 `decide`。

全流程不得停在 06。预算和沟通不是支撑组，必须在测量前走完。

## 2. 三条产品线（销售只能卖这三条）

| `{sop_stage}` | 测量任务 | 对外可写 | 禁止写 |
|---|---|---|---|
| 诊断 | `noise` + `baseline` | 各 App 现在长什么样；Issue | L1 有效果；已优化成功 |
| 冲刺 | 一轮**一类**证据 + `retest` | 受控前后描述 | 确认性 L1（除非对照已隔离） |
| 续约 | `weekly` + `calib` | 14 日滚动异常 | 用周报重开因果 |

确认性 L1 不是产品线，是冲刺里极少达到的门：仅当 `causal_claim=did_isolated` 且主终点 DiD 95% CI 不含 0。默认 `descriptive_until_isolation`。

## 3. 门（未过不得进入下一过程组）

```text
G0  01→02   范围签字；禁售已读
G1  02→07   章程批准；sop_stage 锁定；验收字段齐
G6  07→08   人时按平台×问法；报价排除 L1
G7  08→03   干系人与 comms_bound 锁定
G3  03→04   02 已灌入配置并冻结；freeze_id 写出
G2  04→05   进度不含超出 sop_stage 的窗；plan_hours>0 且不超 budget_hours
G5  05→06   仅冲刺：一类证据 + 监测组未改页 + 完成日/等待（诊断填不适用）
G4  06→09   verdict_4 与 03、05 相同；案件出数路径；已接收
G8  09      资产沉淀不泄漏；不得重开 L1；清单一致且中转清空
```

任何门如果产生测量手册禁止的句子，是本 SOP 让步，不是测量让步。

## 4. 主路径

全流程顺序（不得颠倒）：01→02→07→08→03→04→05→06→09。

```mermaid
flowchart LR
  A[01 洽谈] --> B[02 需求锁定]
  B --> G[07 预算]
  G --> H[08 沟通]
  H --> C[03 测量冻结出数]
  C --> D[04 只排允许窗]
  D --> E[05 实施控制]
  E --> F[06 交付=四选一]
  F --> I[09 收尾]
```

`sop_stage` 在 02 锁定后，07–09 只执行该行允许集。诊断单禁止 05 改页、禁止 07 把干预写入必做行。测量未出噪声底，不得解释涨跌。

## 6. 开一单怎么用模板

1. `python3 agent_pm/run.py init CASE`，然后每次先 `guide CASE` 把说明书给人。  
2. Agent 按说明书 `apply`；人按「材料放哪」交件，再 `decide --actor human`。  
3. 02 锁定后先走 07 预算、08 沟通，再把共享配置复制进 `流程/03 测量/案件/{本案}/冻结/`。  
4. 06 只提交 03 已写出的 `verdict_4`。  
5. 09 对照 06 关项，人只审核与决策，见 `agent_pm/agents/HUMAN.md`。  
6. 全程材料进 `流程/10 项目文件/案件/{本案}/`；每次 `guide` 看中转看板。

## 7. 文件库（10，全程）

`流程/10 项目文件` 与 01–09 并行，开单即建：

1. Agent 带人产出的资料、数据进 `案件/{本案}/原始/{阶段}/`。  
2. 门批准后正式件进 `正式/`，`清单.csv` 做配置管理，版本只增不改。  
3. 成员互传走 `中转/`，看板实时列出待取；不另做即时通讯软件。

测量金标准仍在 `流程/03 测量/`。本库不管口径，管文件位置和版本。见 `流程/10 项目文件/AGENT.md`。

权威顺序：`流程/03 测量` 手册与出数脚本 > [核心合同.md](核心合同.md) > 本 SOP > 各阶段 README。
