# GEO 商业项目

在用户会打的**无品牌原话**上，提高品牌在国内消费级 AI App 里被正确提及的概率，并用冻结词表上的分布证明是否可描述地移动。

打开本文件夹即开工：先读 [AGENTS.md](AGENTS.md)。人只交材料和拍板。不要只做到 06。不要另做软件。

## 仓库怎么分层

四层分开，根目录只留入口：

| 层 | 目录 | 放什么 | 不放什么 |
|---|---|---|---|
| 入口 | `AGENTS.md` `README.md` | 怎么开工 | 长文、脚本、论文 |
| 流程 | [`流程/`](流程/README.md)（01–10） | 带人节点、模板、测量运行时 | 研究全文、引擎实现 |
| 规格 | [`合同/`](合同/README.md) | SOP、核心合同、字段、案件卡 | 某一客户的填空 |
| 实现 | [`工程/`](工程/README.md) + `agent_pm/` | 状态机、检查器、测试 | 业务口径 |
| 知识 | [`研究/`](研究/README.md) | 测量文献与精读 | 当日采集、出数 |

`流程/10 项目文件` 是全程文件库（原始 / 正式版本 / 中转），不是 09 之后多一站。

## 不要做的事

- 把具体客户写进模板原件。
- 用 API / 网页代替手机 App 金标准。
- 未冻结、未采噪声底就解释环比。
- 保证推荐或报名增长。
